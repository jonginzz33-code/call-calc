# 계산기

대리운전 콜 목록 화면에서 거리(km), 시간(분), 금액(원)을 읽어 줄마다 계산값을 보여 주고, 지역에 따라 색으로 표시하는 안드로이드 앱이에요.

v0.2부터 **실시간 모드**가 들어갔어요. 콜 앱을 열어 두면 화면의 글자를 읽어서, 콜 줄마다 계산값과 색 표시를 바로 띄워 줘요. 스크린샷을 골라 시험해 보는 기능도 그대로 있어요.

> 콜 앱에 따라 약관으로 보조 프로그램 사용을 금지할 수 있으니, 쓰기 전에 확인하세요.

이 앱은 읽고 계산해서 보여 주기만 해요. 자동 터치, 자동 수락은 없어요. 인터넷은 새 버전 확인과 받기에만 쓰고, 화면에서 읽은 콜 내용은 밖으로 보내지 않아요.

## 1. APK 받기 (폰에서)

**가장 쉬운 방법:** 폰 브라우저에서 아래 주소를 열면 최신 APK가 바로 받아져요 (압축 풀기 필요 없음).
https://github.com/jonginzz33-code/call-calc/releases/latest/download/call-calc.apk

받은 뒤 아래 "2. 설치하기"로 가요. 처음 한 번만 이렇게 설치하면, 그다음부터는 앱이 스스로 업데이트해요 (아래 "자동 업데이트" 참고).

**Actions 산출물로 받는 방법 (위 방법이 안 될 때):**

1. 폰 브라우저(크롬 등)에서 https://github.com/jonginzz33-code/call-calc 를 열어요.
2. GitHub에 로그인되어 있는지 확인해요. (산출물은 로그인해야 받을 수 있어요.)
3. 화면 위쪽 메뉴에서 **Actions** 탭을 눌러요. 메뉴가 안 보이면 오른쪽 위 `≡` 또는 화면을 옆으로 밀어서 찾아요.
4. 목록 맨 위에 있는 실행(초록색 ✓ 표시)을 눌러요. 노란 동그라미는 아직 만드는 중이니 몇 분 기다려요. 빨간 ✗ 는 실패한 것이에요.
5. 아래로 내려 **Artifacts** 부분에서 `call-calc-v0.1` 을 눌러 내려받아요.
6. 받은 파일은 `call-calc-v0.1.zip` 이에요. **내 파일** 앱(또는 파일 관리자)에서 다운로드 폴더를 열고, 이 zip 파일을 눌러 **압축 풀기**를 해요.
7. 압축을 풀면 `call-calc-v0.1.apk` 가 나와요.

## 2. 설치하기

1. `call-calc-v0.1.apk` 를 눌러요.
2. "출처를 알 수 없는 앱" 또는 "이 출처의 앱 설치 허용" 안내가 나오면 **설정**을 눌러요.
3. 지금 쓰는 앱(내 파일, 크롬 등) 옆의 **이 출처 허용** 스위치를 켜요.
4. 뒤로 가기를 누르면 설치 화면으로 돌아와요. **설치**를 눌러요.
5. "Play 프로텍트" 경고가 나오면 **세부정보 더보기 → 무시하고 설치**를 눌러요. (개인용 앱이라 스토어 검사를 받지 않아서 나오는 경고예요.)
6. 설치가 끝나면 **열기**를 눌러요. 앱 이름은 **계산기**예요.

새 버전을 받을 때도 같은 순서로 하면 돼요. 기존 앱 위에 덮어 설치되고, 설정은 그대로 남아요.

## 2-1. 자동 업데이트

v0.1.1부터는 앱이 스스로 새 버전을 확인해요.
1. 앱을 켜면 새 버전이 있는지 확인해요. 있으면 "새 버전이 있어요" 창이 떠요.
2. **업데이트**를 눌러요.
3. 처음 한 번은 "이 출처의 앱 허용" 설정 화면이 나와요. **계산기** 옆 스위치를 켜고 뒤로 가기를 눌러요. 그리고 다시 **업데이트**를 눌러요.
4. 받기가 끝나면 설치 화면이 나와요. **업데이트**(또는 설치)를 눌러요. 설정은 그대로 남아요.
- 직접 확인하려면 메인 화면 오른쪽 위 **⟳ 업데이트** 또는 **설정 맨 위 [⟳ 업데이트 확인]**을 눌러요. 지금 버전과 최신 버전이 같이 나와요.
- "이 출처 허용"을 켜고 뒤로 가기를 누르면 받기가 바로 이어져요.
- 앱 안에서 안 받아지면 **브라우저로 받기**를 눌러요. 받은 파일을 눌러 설치하면 돼요.
- 자동 확인을 끄려면 **설정 → 업데이트**의 스위치를 꺼요.
- v0.1을 쓰고 있다면 그 버전에는 자동 업데이트가 없어서, 위 "가장 쉬운 방법" 주소로 한 번만 직접 받아 설치해 주세요.

## 3. 권한 켜기

꺼진 권한이 있으면 **앱을 켤 때 바로 안내 창이 떠요.** 창에서 **[켜러 가기]**를 누르면 해당 설정 화면이 열리고, 켜고 뒤로 가기를 누르면 앱으로 돌아와요. 다 켜지면 창이 저절로 닫혀요. **[나중에]**를 누르면 앱을 다시 켤 때 또 알려 줘요.
권한 상태는 **설정 → 권한**에서도 볼 수 있어요 (✅ 켜짐 / ❌ 꺼짐).

지금 버전에서 쓰는 권한:
- **접근성 (계산기)**: 콜 앱 화면의 글자를 읽고, 콜 옆에 계산값을 띄워요. (실시간 모드)
- **이 출처의 앱 허용**: 새 버전을 앱이 스스로 설치하는 데 필요해요.
- **화면 캡처**: 접근성으로 글자가 안 읽히는 콜 앱일 때만 써요. 앱에서 [화면 캡처 시작]을 누르면 허락 창이 떠요.

### 접근성 켜는 법 (한 단계씩)
1. 앱을 켜면 뜨는 안내 창에서 **접근성 → [켜러 가기 →]**를 눌러요. (메인 화면의 [접근성 켜기]도 같아요.)
2. **계산기 스위치 화면이 바로 열려요.** 화면 아래에 할 일이 잠깐 떠요.
   - 안드로이드 12 이하이거나 바로 안 열리는 폰은 접근성 첫 화면이 열려요. 그때는 **설치된 앱 → 계산기**를 눌러요.
3. 스위치를 켜고, 확인 창에서 **허용**을 눌러요.
4. **켜지는 순간 자동으로 계산기로 돌아와요.** "✅ 켜졌어요"가 떠요. (안 돌아오면 뒤로 가기)

**스위치가 회색으로 잠겨서 안 켜질 때** (안드로이드 13 이상, 스토어 밖에서 설치한 앱이라 그래요)
1. 안내 창의 **[앱 정보 열기]**를 눌러요. (또는 설정 → 애플리케이션 → 계산기)
2. 오른쪽 위 **⋮** (점 세 개)를 눌러요.
3. **제한된 설정 허용**을 누르고, 화면 잠금(지문·비밀번호)을 확인해요.
4. 뒤로 가서 다시 접근성 **[켜러 가기]**부터 해요.

### 화면 캡처 허용 (필요할 때만)
1. 메인 화면 실시간 모드 칸의 **[화면 캡처 시작]**을 눌러요.
2. 알림 허용 창이 나오면 **허용**을 눌러요. (안 해도 동작은 해요)
3. "계산기로 녹화 또는 전송을 시작할까요?" 창에서 **전체 화면**을 고르고 **시작**을 눌러요.
4. 끌 때는 메인 화면의 **[캡처 중지]** 또는 알림의 **[중지]**를 눌러요.
- **화면이 꺼지거나 잠기면 안드로이드가 화면 캡처를 자동으로 꺼요.** (보안 규칙이라 앱에서 막을 수 없어요) 그러면 위쪽 띠와 메인 화면에 "화면 캡처가 꺼졌어요"가 떠요. [화면 캡처 시작]을 다시 눌러 주세요. 접근성 방식은 화면이 꺼져도 상관없어요.
- 콜 앱이 캡처를 막아 두었으면 화면이 검게 찍혀요. 그때는 "화면 캡처가 막혀 있어요"라고 알려 줘요. (막힌 걸 뚫지는 않아요)

사진은 안드로이드의 사진 선택 창으로 고르기 때문에 저장공간 권한도 필요 없어요.

다음 버전에서 아래 권한을 쓰게 되면, 그때 켜는 법을 여기에 한 단계씩 추가할게요.
- 접근성 (v0.2: 콜 앱 화면 글자 읽기)
- 화면 캡처 허용 (v0.2: 접근성으로 안 읽힐 때)
- 다른 앱 위에 표시 (v0.3: 오버레이)

## 4. 사용법

### 🔔 좋은 콜 알림
- 메인 화면 **맨 위**에 있어요. 분당 금액이 정한 값(기본 **1,000원**) 이상인 콜이 보이면 **진동 + 소리**가 울리고, 맨 위에 `🔥 분당 1,050 · 공덕동 · 16,000`이 6초 동안 떠요.
- 같은 콜은 한 번만 알려요. 빨강(가면 안 됨) 지역 콜은 알리지 않아요.
- 지금은 "터치할 때만" 읽는 방식이라, 화면을 만져서 읽을 때 좋은 콜이 있으면 울려요.

### 📊 오늘 통계 (맨 위 투명 글씨)
- 콜 앱 위 맨 위에 `오늘 평균 312 · 최고 556 · 최저 210 · 37건 · 접근성 · ⏱7ms`처럼 배경 없이 글씨만 떠요.
- **하루 = 오후 5시 ~ 다음 날 오전 6시** (설정 → 실시간 표시 → 오늘 통계에서 바꾸기). 그 밖의 시간에 본 콜은 빼요.
- 같은 콜은 한 번만 세요 (거리·시간·금액이 같고, 출발지·도착지가 거의 같고, 10분 안에 다시 보이면 같은 콜).
- **접근성 / 캡처**: 이번에 어떤 방식으로 읽었는지예요. 접근성이면 빠르고 화면이 꺼져도 괜찮아요.
- 기록은 폰 안에만 저장하고 3일 지나면 지워요.

### 🟢 콜 확인 (두 구간 + 분당 금액)
1. 콜 목록에서 콜을 눌러 **상세 화면**([콜 수락하기]가 있는 화면)을 열어요.
2. 초록 **[콜 확인]** 버튼을 눌러요.
3. 가운데에 결과가 떠요 (TMAP 실시간 교통, 차 기준).
   - **① 내 위치 → 출발지** (픽업): 도로 거리 · 시간
   - **② 출발지 → 도착지** (운행): 도로 거리 · 시간
   - **총 시간 (①+②)**, **금액 (실수익)**
   - **톨비**: ② 운행 경로의 통행료 (TMAP 추천 경로, 승용차)
   - **분당 금액 = (실수익 − 톨비) ÷ 총 시간** (좋은 콜 기준 이상이면 초록, 기준 단가보다 낮으면 회색)
4. 결과 창을 누르면 닫혀요. 수락은 직접 하세요.
- **빠르게**: 상세 화면이 열리면 뒤에서 미리 계산해 둬서, 조금 있다 누르면 바로 떠요. 같은 콜은 3분 동안 기억해요. 위치도 콜 앱이 떠 있는 동안 30초마다 미리 잡아 둬요. 결과는 나오는 대로 (픽업 먼저) 채워져요.
- 길찾기가 안 되면 "약 ○km / 약 ○분"으로 추정값을 보여 줘요 (픽업: 직선 × 1.3, 시간은 픽업 1km당 분 설정 / 운행: 콜 앱 안내 시간).
- 누를 때 화면을 새로 읽어요. 사진(갤러리)으로 시험할 땐 [화면 캡처 시작]을 먼저 눌러 주세요.
- **누를 때와 상세 화면이 열릴 때** 출발지·도착지 이름과 내 위치를 TMAP에 보내요 (금액 등은 안 보냄). TMAP 무료 하루 10,000건.
- **TMAP 앱 키 넣기**: 설정 → 실시간 표시 → 콜 확인 → **TMAP 앱 키 붙여 넣기** 칸.
  - 키는 SK오픈API(openapi.sk.com) → 대시보드 → 앱 → **앱키(appKey)** 탭에 있어요.
  - 그 앱에 **TMAP 상품(Free)**이 신청돼 있어야 해요: PRODUCTS → TMAP → API 사용 요금 → Free [사용하기].
- **위치 권한**이 필요해요. 앱을 켜면 안내 창에서 켤 수 있어요.

### 앱 종료
- 메인 화면 실시간 모드 칸 아래 **[⏻ 앱 종료]**를 누르면 둥근 버튼, 계산값 표시, 화면 캡처, 읽기가 모두 멈추고 앱이 닫혀요.
- 또는 둥근 **[콜 ON]** 버튼을 끌면 화면 맨 위에 **🗑 쓰레기통**이 나타나요. 거기에 끌어다 놓으면(빨갛게 커지면 손 떼기) 똑같이 종료돼요.
- 다시 쓰려면 앱을 열기만 하면 돼요. 자동으로 다시 켜져요. (접근성은 켜 둔 그대로라 다시 켤 필요 없어요)

### 실시간 모드 (콜 앱 위에 띄우기)
1. 접근성을 켜요 (위 3번).
2. 앱이 **"어느 콜 앱 위에 띄울까요?"** 하고 물으면 쓰는 콜 앱에 체크하고 **저장**을 눌러요. (나중에 바꾸려면 메인 화면 [감시할 앱 고르기] 또는 설정 → 실시간 표시)
3. 콜 앱을 열어요. 화면 옆에 둥근 **[콜 ON]** 버튼이 생겨요.
4. 콜 목록에서 줄마다 오른쪽 아래 빈자리에 계산값이 떠요.
   - **★ 초록**: 보이는 콜 중 제일 좋음 / **⛔ 빨강**: 가면 안 되는 지역 / **⚠ 노랑**: 주의 / **회색**: 기준 미달 / **?**: 읽기 실패
5. 둥근 버튼: **한 번 톡** 표시 켜기·끄기, **끌면** 위치 이동(기억됨), **두 번 톡 또는 길게** 누르면 메뉴(읽을 영역 정하기 · 기억한 콜 지우기 · 표시 끄기).
6. 스크롤하는 동안엔 표시가 잠깐 숨고, 멈추면 다시 읽어서 붙여요. 위아래로 잘린 줄은 건너뛰어요.
7. **화면 어디든 만지면 바로 새로고침**돼요. (톡 터치, 밀기, 스크롤 등. 터치는 그대로 아래 앱에 전달돼요.)
   - 기본은 **터치할 때만**이에요. 손대지 않으면 표시가 멈춰 있어서 깜빡이지 않아요. 새 콜이 올라오면 화면을 톡 한 번 쳐 주세요.
   - 설정 → 실시간 표시 → **새로고침 방식**에서 **자동 + 터치**(화면이 바뀌면 저절로도 읽기)로 바꿀 수 있어요.
   - 계산값 표시는 읽은 영역(네모) 안, 정하지 않았으면 화면 안에서만 떠요.
8. 화면 맨 위 작은 띠에 지금 계산식, (설정 시) 지나온 콜 중 최고, ⏱ 걸린 시간이 나와요.
- 콜 앱이 아닌 다른 앱으로 가면 표시와 버튼이 사라져요. (항상 표시를 켜면 모든 앱에서 떠요)
- 감시할 앱 고르기 창 위쪽 **검색칸**에 앱 이름 일부(예: 대리, 카카오)를 치면 목록이 바로 줄어요. 고른 앱은 맨 위에 보여요.

### 읽을 영역 정하기 (네모 틀) → 더 빠르게
1. 콜 앱에서 둥근 **[콜 ON]**을 **두 번 톡** (또는 길게) 눌러요.
2. 메뉴에서 **[▢ 읽을 영역 정하기]**를 눌러요.
3. 반투명 네모 틀이 떠요. **가운데를 끌면 이동**, **네 모서리 동그라미를 끌면 크기 조절**이에요. 콜 목록만 딱 들어가게 맞춰요.
4. 아래 **[저장]**을 눌러요. 이제 네모 안만 읽어요. (네모 밖이 바뀌어도 다시 읽지 않아서 더 빨라요)
- **[전체 화면]**: 네모를 지우고 다시 전체를 읽어요. **[취소]**: 바꾸지 않아요.
- 영역은 앱마다 따로 기억해요. 설정 → 실시간 표시 → [읽을 영역 모두 지우기]로 한꺼번에 지울 수 있어요.

### 화면이 꺼질 때
- 안드로이드는 화면이 꺼지거나 잠기면 화면 캡처를 끊어요 (보안 규칙, 막을 수 없어요).
- **화면 꺼짐 방지** (기본 켜짐): 감시하는 앱이 떠 있는 동안은 화면이 저절로 꺼지지 않아요. 전원 버튼으로 끄면 꺼져요.
- **화면을 다시 켜면 시작 창 자동으로** (기본 켜짐): 끊겼으면 잠금을 풀자마자 허락 창이 떠요. **[시작]**만 누르면 다시 읽어요.
- 둘 다 설정 → 실시간 표시에서 끌 수 있어요. 접근성 방식은 화면이 꺼져도 상관없어요.

### 스크린샷으로 실시간 표시 시험하기 (항상 표시)
1. 메인 화면 실시간 모드 칸의 **항상 표시** 스위치를 켜요. (설정 → 실시간 표시에도 있어요)
2. **[화면 캡처 시작]**을 누르고 허락해요. 사진 속 글자는 접근성으로 못 읽어서 화면 캡처가 필요해요.
3. 갤러리에서 콜 목록 스크린샷을 열어요. 잠시 뒤 콜 줄마다 계산값이 떠요.
4. 실제로 쓸 때는 **항상 표시**를 끄고 감시할 앱을 골라요.
- 접근성으로 콜을 못 읽는 앱이면 띠에 "글자를 못 읽었어요 · [화면 캡처 시작]을 눌러 주세요"가 떠요. 그때 화면 캡처를 켜요.

**설정 → 실시간 표시**에서 고를 수 있는 것
- 읽는 방식: 자동(기본) / 접근성만 / 화면 캡처만
- '제일 좋음' 범위: 지금 보이는 콜 중(기본) / 스크롤로 지나온 콜 전체 중 → 위 띠에 "최고: 초지동 12,000 (736)"처럼 보여 줘요. 다른 화면으로 넘어가면 기억이 지워져요.
- 표시 방식: 터치 통과(기본, 표시 위를 눌러도 콜이 눌려요, 불투명도 최대 80%) / 진하게(최대 100%, 누를 땐 둥근 버튼으로 숨기기)
- 불투명도, 표시 글자 크기


### 스크린샷 고르기
1. 콜 앱에서 콜 목록 화면을 띄우고 스크린샷을 찍어요. (보통 전원 버튼 + 소리 줄이기 버튼을 같이 누르기)
2. 계산기 앱을 열고 **스크린샷 고르기**를 눌러요.
3. 방금 찍은 사진을 골라요.
4. 잠시 뒤 찾은 콜이 위에서부터 차례로 나와요.

갤러리에서 사진을 열고 **공유 → 계산기**를 눌러도 돼요.

사진이 없을 때는 **예시 3줄로 해 보기**를 누르면 설명서의 예시 화면으로 바로 확인할 수 있어요.

### 결과 보는 법
- 큰 숫자: 계산값 (반올림)
- **★ 초록 테두리**: 지금 보이는 콜 중 계산값이 가장 높은 콜 (제일 좋음). 빨강 지역 콜은 여기서 빠져요.
- **흐린 회색**: 기준 단가보다 낮은 콜 (기준 미달)
- **빨강 바탕 ⛔**: 가면 안 되는 지역 / **노랑 바탕 ⚠**: 주의 지역 / **초록 바탕 👍**: 선호 지역
- **읽기 실패**: 거리, 시간, 금액 중 하나라도 못 읽은 콜. 틀린 값으로 계산하지 않으려고 계산하지 않아요.
- 카드를 누르면 그 콜로 묶인 원본 글자가 펼쳐져요.
- 맨 아래 **인식한 원본 글자 보기**를 누르면 사진에서 읽은 글자가 전부 나와요. 숫자를 잘못 읽었는지 확인할 때 써요.
- ⏱ 표시는 읽고 계산하는 데 걸린 시간이에요. 설정에서 끌 수 있어요.

### 계산식 바꾸기
- 메인 화면의 **계산식 … 바꾸기 ▾** 칸을 누르면 저장된 식 중에서 바로 고를 수 있어요.
- 식을 새로 만들거나 고치려면 **설정 → 계산식**으로 가요.
  1. **+ 식 추가**를 눌러요.
  2. 이름(예: 시간당 금액)과 식을 입력해요. A = 거리(km), B = 시간(분), C = 금액(원)이에요. 아래 글자 버튼(A B C + − × ÷ 괄호)을 눌러 넣어도 돼요.
  3. 식 아래에 ✓ 와 예시 계산값이 나오면 올바른 식이에요. ✗ 가 나오면 설명대로 고쳐요.
  4. **저장**을 눌러요. 새로 만든 식이 바로 선택돼요.
- **기본 식: 1분당 금액 `C ÷ (P + B)`** (기본 선택)
  - A = 픽업 거리(km), B = 운행 시간(분), C = 금액(원)
  - **P = 픽업 시간(분) = 픽업 거리 × 1km당 분, 반올림**
  - 예: 8.4km · 28분 · 16,000원 → 픽업 8.4 × 2 = 16.8 → **17분**, 17 + 28 = 45분, 16,000 ÷ 45 = **356** (1분당 356원)
- 그 밖의 식: `C ÷ (A + B)`, `C ÷ B`, `C ÷ A`
- **픽업 1km당 몇 분**: 시간대마다 달라서 바꿀 수 있어요. 메인 화면 계산식 아래 **[1분] [2분] [3분] [5분]** 버튼을 누르거나, 설정 → 계산식 → 픽업 1km당 몇 분에서 직접 입력(예: 2.5)해요. 기본은 2분이에요.
- **기본값으로 되돌리기**를 누르면 기본 식 3개로 돌아가요.
- 0으로 나누게 되면 "계산 불가"로 나와요.

### 기준 단가와 최소 금액
- **설정 → 기준값 → 기준 단가**에 숫자를 넣으면, 계산값이 그보다 작은 콜은 흐린 회색이 돼요. 비워 두면 안 써요.
- **최소 금액** 스위치를 켜고 금액을 넣으면, 그보다 싼 콜은 목록에서 숨겨요.

### 지역 단어 등록하기
1. **설정 → 지역 단어 → + 단어 추가**를 눌러요.
2. 단어를 입력해요 (예: 안산, 부천, 심곡동). 주소에 이 단어가 **들어 있으면** 걸려요. "안산"을 넣으면 "안산시 단원구", "안산시 상록구" 모두 걸려요.
3. 색을 골라요: 빨강(가면 안 됨), 노랑(주의), 초록(선호).
4. 필요하면 메모를 써요 (예: 금액 좋아도 가지 말 것). 메모는 결과 카드에 같이 나와요.
5. **저장**을 눌러요.
- 단어를 누르거나 **수정**을 누르면 고칠 수 있어요. 지우려면 수정 창 왼쪽 아래 **삭제**를 눌러요. (계산식도 같아요.)
- **검사할 주소**: 기본은 도착지만 봐요. "출발지도 포함"을 고르면 출발지도 같이 봐요.
- **빨강 지역 콜**: 기본은 계산값을 보여 주고 경고만 붙여요. "계산값 숨기기"를 고르면 숫자 대신 — 로 나와요.

## 개발 메모

- `core/`: 안드로이드와 상관없는 순수 Kotlin. 줄 묶기·숫자 추출(`CallParser.kt`), 계산식 파서(`Expr.kt`), 지역 판정·계산(`Evaluate.kt`). 단위 테스트는 `core/src/test`.
- `app/`: 안드로이드 화면과 ML Kit 한국어 글자 인식(앱에 포함된 모델).
- GitHub Actions(`.github/workflows/build.yml`)가 main 에 푸시할 때마다 테스트 → APK 빌드 → 산출물 업로드 → 릴리스(`build-번호`, 파일 `call-calc.apk`)를 해요.
- 앱 자동 업데이트(`Updater.kt`)는 최신 릴리스 본문의 `versionCode=`를 지금 앱의 버전 번호와 비교해요. 버전 번호는 빌드 번호 + 1이라 푸시할 때마다 올라가요.
- 버전 이름은 이 README 맨 끝의 `## v…` 줄에서 자동으로 읽어요. 버전을 올릴 때는 아래에 새 항목을 추가하면 돼요.
